# 通讯录

软件工程极限编程作业，两人合作开发的网页通讯录。

## 计划功能

- 联系人新增、查看、编辑和删除
- 收藏联系人及查看收藏列表
- 为联系人添加多种联系方式
- Excel 导入和导出

## 技术方案

使用 HTML、CSS 和 JavaScript 构建单页面应用，联系人保存在浏览器 localStorage 中，计划使用 SheetJS 处理 Excel。项目尚在准备阶段，运行方式将在代码完成后补充。
